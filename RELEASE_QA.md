# Release QA — The IAH Vyuha v2.0.0

## Automated checks

- JavaScript syntax check: required.
- Runtime mock initialization: required.
- 3 chapters × 6 story phases: required.
- Hidden Echo cycle: 8 phases: required.
- Phase Echo decoy: required.
- Human-like Warden role set: required.
- Ashen Naga boss phase/spawn alignment: required.
- Required HTML/JS DOM identifiers: required.
- Single-file runtime wiring: required.

## Manual smoke matrix

Test on current Chrome/Edge/Firefox/Safari where available, at desktop, tablet and mobile widths. Verify pointer lock, mouse look, WASD, touch stick, fire, Phase Echo, Hint, pause/resume, chapter transitions, boss encounter, audio permission and offline reload.

## Known limitations

- Rendering is a dependency-free 2.5D/raycasting approach, not a full WebGL AAA engine.
- Final commercial art, animation, voice, accessibility certification and payment infrastructure are not included.
- Genie 3 and Google Maps integrations require authorized external services and current licensing/terms.
- Automated browser certification is not a substitute for real-device testing.
